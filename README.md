A program that writes one invented English word with a one-line definition to /output/entry.txt for make.fun's "Invent a Word We Need" bounty — a single line, under 140 characters, judged pairwise by a lexicographer judge on whether the word fills a real gap, how exact the definition lands in one reading, how sayable, spellable and memorable the word is, and how fresh and surprising the pairing feels.

## Run it

```sh
python3 main.py
```
